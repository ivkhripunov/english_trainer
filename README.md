# Тренажёр языков

Веб-приложение для изучения иностранной лексики с карточками, подборками и тестами.
Написано на Python/Django в рамках учебного проекта.

## Возможности

- **Языки** — добавляй любые языки для изучения
- **Подборки** — создавай независимые наборы слов для каждого языка
- **Словарь** — добавляй, редактируй и удаляй слова (CRUD)
- **Тест** — проверяй знания в двух направлениях: Оригинал→Перевод и Перевод→Оригинал
- **Статистика** — отслеживай точность по каждому слову и подборке
- **Поиск и фильтрация** — поиск по словам, фильтр по подборкам, сортировка
- **Валидация** — все формы защищены от некорректного ввода

## Технологии

- Python 3.10+
- Django 4.2
- Bootstrap 5.3
- SQLite (встроенная БД)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone git@github.com:ivkhripunov/english_trainer.git
cd english_trainer

# 2. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Применить миграции
python manage.py migrate

# 5. Загрузить тестовые данные (опционально)
python manage.py loaddata fixtures/initial_words.json

# 6. Запустить сервер
python manage.py runserver
```

Открыть в браузере: http://127.0.0.1:8000/
